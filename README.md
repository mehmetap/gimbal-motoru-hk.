# Gimbal motoru çalışması

Bu depoda henüz motor kontrol kaynak kodu veya derleme projesi bulunmuyor.
[Motor kodları issue #1](https://github.com/mehmetap/gimbal-motoru-hk./issues/1) ayrı bir ZIP eki içeriyor; ek dosya depodaki sürümlenmiş kaynak yerine geçmez.

## Tamamlanması gerekenler

- Kaynakları uygun src/ klasörüne eklemek.
- Kart, motor, sürücü, besleme ve bağlantı bilgilerini belgelemek.
- Kullanılan IDE, kütüphaneler ve sürümlerini belirtmek.
- Hata mesajı, tekrar adımları ve beklenen davranışı eklemek.

Kaynak ve donanım olmadan derleme veya motor testi yapılmadı.
