# Gimbal Motoru Çalışması

Bu depoda henüz kaynak kod veya çalıştırılabilir proje bulunmuyor.

## Mevcut kaynak

[Issue #1 — motor kodları](https://github.com/mehmetap/gimbal-motoru-hk./issues/1)
şu arşive bağlantı içerir:
[gimbal-lab-web.zip](https://github.com/user-attachments/files/30387328/gimbal-lab-web.zip).
Arşiv bu inceleme ortamında indirilemedi; içeriği veya motor sürme kodu doğrulanmadı.

## Projeyi tamamlamak için

Arşivdeki kaynakları depoya açarak ekleyin. Web dosyaları için `web/`,
firmware varsa `firmware/`, bağlantı ve kalibrasyon belgeleri için `docs/`
kullanılabilir. Kullanılan kart, motor/sürücü modeli, besleme gerilimi ve
pin bağlantıları belgelenmeden donanım kurulumu tarif edilemez.

Hata raporunda çalıştırma adımları, beklenen/gerçek davranış ve hata çıktısı
bulunmalı. Kaynaklar eklenene kadar derleme veya donanım testinin geçtiği söylenemez.
